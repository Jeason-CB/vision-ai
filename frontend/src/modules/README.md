# Módulos funcionales alineados al informe
- dashboard: KPI y actividad derivados de registros.
- analysis: carga, preprocesamiento, inferencia y visor.
- detections: clases, confianza, cajas y características geométricas.
- segmentation: máscaras por instancia cuando el modelo las produce.
- patterns: espacio para reglas de negocio y evidencia por escenario.
- alerts: revisión humana de alertas.
- history: consulta de análisis y exportación.
- scenarios: seguridad industrial, almacén inteligente, calidad y retail.
- settings: parámetros de análisis y umbrales.
