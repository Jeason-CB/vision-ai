VISION AI - VERSION DE MONITOREO POR VIDEO

1. Descomprime la carpeta completa.
2. Ejecuta INICIAR_WINDOWS.bat.
3. En el navegador, abre Monitoreo en vivo.
4. Permite el acceso a la cámara o selecciona un video.
5. Pulsa Iniciar monitoreo.
6. Para grabar, usa Iniciar grabación local y luego Detener y guardar grabación.

IMPORTANTE:
- Esta versión procesa cámara web y archivos de video locales.
- La conexión directa a cámaras IP/NVR por RTSP no está implementada todavía.
- La primera instalación necesita Internet para instalar dependencias y descargar el modelo YOLO.
- El modelo COCO no reconoce identidades ni atributos especializados como casco o uniforme.
- Revisa README.md para requisitos, arquitectura, API y limitaciones.
